Call of Yuki Studio

Paste a script. Yuki narrates it, and the finished video can go straight to your channel.

One-time setup

Paste your GitHub token (fine-grained, only for the yuki-video repo, with Contents and Actions set to read & write). It stays in this browser only.

Tips

Cloned voice takes a few hours for a long script because it runs on free servers. Use the quick voice to check the video first. Leave the page open or come back later: runs continue without you, and the YouTube link is saved in the results folder of the repo.
